Expand description

A card’s alignment state - where the board model says the card is, where the card layer stored the transform stack, and where the card actually renders. Diagnostics API for input-region coverage checks: the alignment invariant is rendered.center() == position (rotation and scale apply around the center, so the rendered AABB stays centered), and drift quantifies the violation.

Fields§

§card_id: CardId

The card’s id.

§position: CardPosition

Model center position in workspace coordinates.

§placed: Option<Vec2<Pixels>>

Stored put spot of the transform stack on the layer - None while the widget tree is not attached yet.

§rendered: Option<Rect<Pixels>>

Rendered bounds in widget coordinates - None while the card is not on a board or not realized yet.

§drift: Option<Vec2<Pixels>>

Rendered-center minus model position - the alignment invariant’s violation; None while the card does not render.
