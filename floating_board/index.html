§floating-board

A GTK4 widget that renders freely movable, rotatable and scalable cards on top of an application’s content - designed for table-top multitouch surfaces where there is no “up” or “down”.

§Layers

┌─────────────────────────────────────────────────────────────────┐
│ Consumer application                                            │
├─────────────────────────────────────────────────────────────────┤
│ widget/   - thin GTK glue (gestures, layout, transforms)         │
├─────────────────────────────────────────────────────────────────┤
│ domain/   - pure Rust: newtypes, geometry math, layout serde     │
└─────────────────────────────────────────────────────────────────┘

§Quick start

use floating_board::CardAnchor;
use floating_board::CardConfig;
use floating_board::FloatingBoard;

let board = FloatingBoard::new(content);
let id = board.add_card(
    controls,
    CardConfig {
        title: Some("Controls".into()),
        position: CardAnchor::BottomCenter,
        ..Default::default()
    },
);
let layout = board.layout_snapshot();
board.restore_layout(&layout);

Modules§

domain
Pure, GTK-free domain core: card identity/geometry, board layout and bounds math, and shared geometry primitives. Everything in this module is serializable or pure value/method code and free of gtk4 imports.
widget
GTK widget layer: thin ObjectSubclass glue mapping gestures, layout and transforms onto the pure domain operations in crate::domain.
