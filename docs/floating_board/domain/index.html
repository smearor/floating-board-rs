floating_board

Module domain 

Source
Expand description

Pure, GTK-free domain core: card identity/geometry, board layout and bounds math. Everything in this module is serializable or pure value/method code and free of gtk4 imports.

The circumradius whose rim-shrunk bounding box fits (natural_width, natural_height) for Fill/Clipped content: 2 * (R - ring) >= width and sqrt(3) * (R - ring) >= height. The content underlaps the chrome bars, so no bar inset applies.
hexagon_radius_for
The circumradius whose inscribed content square fits side - [Hexagon::circumradius_for_inscribed_square] is side / (3 - sqrt(3)) - grown by the ring margin, but at least large enough that the centered square clears a combined bar inset bar_inset tall on each flat edge - the sum of the top and bottom band heights (sqrt(3) * R >= side + 2 * bar_inset, expressed as a height-only bounding-size constraint).
