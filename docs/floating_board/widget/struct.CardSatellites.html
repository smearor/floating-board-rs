Expand description

Per-card satellite configuration, stored in CardConfig::satellites.

Carries the layout and interaction semantics for all of the card’s satellites - both the explicit satellites list and chrome elements placed via ChromeSlot::satellite(..), which join the same set.

Fields§

§layout: SatelliteLayout

Layout strategy for this card’s satellites.

§rotation_mode: SatelliteRotationMode

Rotation semantics vs. card rotation.

§collision: SatelliteCollisionMode

Collision handling vs. foreign cards and satellites.

§open: bool

Whether the satellite set starts open (visible). true for a permanently docked sidebar; a radial menu typically starts closed and opens via FloatingBoard::set_satellites_open.

§satellites: Vec<SatelliteConfig>

Configured satellites, in dock/orbit order. Chrome satellites come either from this list (SatelliteKind::Chrome) or from ChromeSlot::satellite entries in CardConfig::chrome.
